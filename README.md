# 🐾 מטיילים עם לונה

אפליקציית ווב משפחתית למעקב אחרי היציאות של לונה: סימון יציאה בלייב או בדיעבד, תמונות, טבלת צדק, ומפה של מי הוציא ומתי.

## הקמה (כ-10 דקות)

### 1. Supabase
1. ב-[supabase.com](https://supabase.com) → **New project** (התוכנית החינמית מספיקה).
2. **SQL Editor** → להדביק את `supabase.sql` (יוצר את הטבלאות walks ו-feedings), **להחליף את `CHANGE-ME` בקוד משפחה** → Run.
3. **Project Settings → API** → להעתיק את **Project URL** ואת המפתח **anon / publishable**.

### 2. חיבור הקובץ
בראש `index.html`:
```js
const CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ...',
};
```
מותר לשים את מפתח ה-anon בקוד פומבי. ההגנה היא קוד המשפחה, שלא נשמר בקוד: כל אחד מקליד אותו פעם אחת בטלפון.

### 3. GitHub Pages
1. ליצור repo חדש (למשל `luna-walks`) ולהעלות את `index.html`.
2. **Settings → Pages → Deploy from branch → main / root**.
3. אחרי דקה האתר זמין בכתובת `https://<user>.github.io/luna-walks/`.

### 4. בטלפונים
פותחים את הקישור, מקלידים את קוד המשפחה ובוחרים "מי אני".
באייפון: שיתוף → **הוספה למסך הבית**. באנדרואיד: ⋮ → **הוספה למסך הבית**. ככה האפליקציה נפתחת כמו אפליקציה רגילה.

## איך זה עובד
- **4 יציאות ביום:** בוקר (4:00–11:00), צהריים (11–14), אחה"צ (14–19), לילה (19:00–4:00). יציאה ב-1 בלילה נספרת ללילה של אתמול.
- **לייב:** "יוצאים עכשיו" מפעיל טיימר עם לונה שהולכת, ואז "חזרנו!" עם תמונה והערה. כל המשפחה רואה שמישהו כבר בחוץ.
- **בדיעבד:** כפתור "תיעוד בדיעבד", או לחיצה על משבצת ריקה בטבלת הצדק.
- **טבלת צדק:** ל-7, 14 או 30 ימים. מראה כמה יציאות כל אחד עשה, כמה הוא מעל או מתחת לחלק ההוגן, משך ממוצע, ומי לוקח את משמרות הלילה והבוקר.
- **האכלות:** כרטיס "האוכל של לונה היום" עם ארוחת צהריים, ארוחת ערב וירקות לפני השינה. לחיצה אחת רושמת מי האכיל ומתי. ארוחה שהגיע זמנה מסומנת בכתום, ואחרי 3 שעות בלי רישום היא מסומנת באדום. ניסיון לרשום ארוחה שכבר נרשמה מקפיץ אזהרה, כדי שלונה לא תאכל פעמיים. יש גם יומן של השבוע האחרון שמראה פספוסים. אין טבלת צדק להאכלות.
- **"התור של…":** מי שהוציא הכי מעט ב-7 הימים האחרונים.
- הנתונים מתרעננים כל 30 שניות וכשחוזרים לאפליקציה.
- **בלי Supabase** האפליקציה רצה במצב הדגמה, והנתונים נשמרים רק במכשיר.

## שינוי שמות וצבעים
מערך `WALKERS` בראש הסקריפט ב-`index.html`. את ה-`id` לא משנים אחרי שיש נתונים.
